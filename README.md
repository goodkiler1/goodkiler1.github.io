# Портфолио

Одностраничный сайт: кто я, какие проекты сделал, чем могу помочь.

**Открыть:** https://goodkiler1.github.io

## Устройство

Один файл `index.html`. Ни сборки, ни зависимостей в проекте.

| Что | Чем сделано |
|---|---|
| Разметка | HTML |
| Стили | Tailwind CSS через CDN |
| Шрифт | Geist и Geist Mono с Google Fonts |
| Хостинг | GitHub Pages |

## Как менять

Открыть `index.html`, поправить текст, сохранить, отправить изменения:

```
git add -A
git commit -m "что изменил"
git push
```

Через минуту правки появятся на сайте.

## Что стоит улучшить

Tailwind через CDN тянет около 100 КБ скрипта при каждой загрузке. Для портфолио
это терпимо, но для клиентских сайтов CSS лучше собирать заранее.
