# Портфолио

Одностраничный сайт: имя, проекты, что умею, контакт.

**Живая версия:** https://goodkiler1.github.io

## Стек

Один файл `index.html`. Tailwind CSS через CDN, шрифты Geist и Geist Mono
с Google Fonts. Сборки нет.

## Оформление

Жёсткий минимализм. Тёмная тема, много воздуха, крупная типографика.

| Что | Значение |
|---|---|
| Фон | `bg-zinc-950` |
| Текст | `text-zinc-100`, приглушённый `text-zinc-400` / `text-zinc-500` |
| Границы | `border-zinc-800` |
| Заголовки секций | `font-mono text-xs uppercase tracking-widest` |

Никаких градиентов, теней и анимаций. Из движения — только подсветка ссылок
при наведении.

## Правила текста

Пользователь называет шаблонные тексты «нейрослопом» и просил так не писать.
**Не добавляй:**

- Блоки статистики («Проектов: 2», «Строк кода: 1058»)
- Секции «Как я работаю» с нумерацией 01/02/03
- Бейджи вида «Свободен для заказов»
- Слова «уникальный», «инновационный», «эксперт», «погрузитесь»
- Самопохвалу: «сделано вручную, без конструкторов»

**Пиши:** короткие фразы, конкретика, только правда. Опыт с 2026 года, два проекта —
так и указано. Придумывать «опыт 4 года, 15 проектов» нельзя: заказчик откроет
GitHub и увидит дату создания репозитория.

Хорошо работают честные ограничения — строка «не берусь за интернет-магазины
и приём платежей» осталась намеренно.

## Деплой

Репозиторий называется `goodkiler1.github.io`, поэтому сайт живёт на корневом
адресе. Обновление:

```
git add -A
git commit -m "что изменил"
git push
```

Через минуту правки на сайте.

## На будущее

Tailwind через CDN тянет около 100 КБ скрипта при каждой загрузке. Для портфолио
терпимо, для клиентских сайтов CSS лучше собирать заранее.
